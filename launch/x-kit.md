## 3. Reply playbook
**Reply under:**
- Plugin or MCP launches for Codex/ChatGPT. Search: `codex plugin`, `"codex" mcp launch`, `chatgpt apps sdk`, `#buildinpublic codex`
- "What plugins/MCPs do you use?" threads
- Complaints a listed plugin solves: secret leaks, agents forgetting context, hitting usage limits, messy handoffs
- Makers we list, when they post updates

**Rules:**
- Add something first. The link comes second, and only if it helps.
- At most 1 link per reply, and no more than ~10 replies a day. Never paste the same text twice.
- Never pitch paid spots in replies. Only bring it up if someone asks how the site makes money, and then say "paid placements, labelled as paid."
- Skip politics, drama, and anyone who seems annoyed.

**Sample replies:**
1. (launch post) Nice, this looks like it fits our Agent Workflows shelf. Want us to list it? If it's already in, here's the page; tell us if the description is off.
2. ("what plugins do you use?") Agent Guard for secrets, deja for searching old sessions, and a usage tracker so I don't hit the wall mid-task. We keep them sorted here: pickaplugin.com
3. ("my agent forgets everything") There's a whole shelf for exactly this, 43 memory plugins, local and hosted: pickaplugin.com/c/memory-context
4. ("keep hitting Codex limits") Codex Usage and Resets projects when you'll run out, so you can plan around it: pickaplugin.com/p/codex-usage-and-resets
5. (a listed maker shipping an update) Congrats on the release. Updated your listing too. Shout if the description needs changing.
